# Customer Shopping Behavior Analysis

An end-to-end data analytics project exploring customer purchasing patterns, product preferences, subscription behavior, and revenue trends using **Python, PostgreSQL, SQL, and Power BI**.

## Project Overview

This project analyzes 3,900 customer purchase records to identify shopping trends, understand customer behavior, and generate actionable business insights.

The analysis focuses on customer segmentation, purchasing patterns, discount effectiveness, subscription behavior, product performance, and revenue distribution to support data-driven business decisions.

## Business Problem

A retail company wants to better understand its customers' shopping behavior to improve sales, customer satisfaction, and long-term customer loyalty.

The objective is to analyze transactional data and identify factors influencing purchasing decisions, customer retention, and product preferences.

## Tools & Technologies

- **Python:** Pandas, NumPy, Jupyter Notebook
- **Database:** PostgreSQL
- **SQL:** Aggregations, Joins, CTEs, Subqueries, Window Functions
- **Data Visualization:** Microsoft Power BI
- **Libraries:** SQLAlchemy, Psycopg2

## Dataset Overview

The dataset contains:

| Attribute | Details |
|---|---|
| Total Records | 3,900 |
| Total Columns | 18 |
| Missing Values | 37 |
| Missing Data | Review Rating |

### Key Features

- Customer demographics: Age, Gender, Location
- Purchase information: Item, Category, Purchase Amount
- Shopping preferences: Season, Size, Color
- Customer behavior: Previous Purchases, Subscription Status
- Transaction details: Discounts, Promo Codes, Shipping Type
- Customer feedback: Review Ratings

## Project Workflow

### 1. Data Preparation & Exploratory Data Analysis (Python)

- Imported and explored the dataset using Pandas.
- Examined data structure and descriptive statistics.
- Handled missing values in the Review Rating column using category-wise median imputation.
- Standardized column names using snake_case.
- Performed feature engineering by creating age groups and purchase frequency features.
- Checked data consistency and removed redundant columns.
- Connected Python with PostgreSQL to load the cleaned dataset.

### 2. SQL Analysis (PostgreSQL)

Executed 10 business-oriented SQL queries to extract insights:

1. Revenue generated by male and female customers.
2. Identification of high-spending customers using discounts.
3. Top 5 products based on average review ratings.
4. Comparison of average purchase amounts across shipping types.
5. Spending and revenue comparison between subscribers and non-subscribers.
6. Products with the highest percentage of discounted purchases.
7. Customer segmentation into New, Returning, and Loyal categories.
8. Top 3 most purchased products within each category.
9. Analysis of repeat buyers and subscription behavior.
10. Revenue contribution across different age groups.

### 3. Power BI Dashboard

Developed an interactive dashboard to visualize customer shopping behavior and business performance.

Dashboard features include:

- Total customers and average purchase amount.
- Average customer review ratings.
- Customer distribution by subscription status.
- Revenue and sales analysis by product category.
- Revenue distribution across age groups.
- Interactive filters for gender, category, shipping type, and subscription status.

## Key Business Insights

- **Customer Segmentation:** Identified 3,116 Loyal, 701 Returning, and 83 New customer records based on previous purchase history.
- **Shipping Preferences:** Express shipping recorded an average purchase amount of $60.48 compared with $58.46 for Standard shipping.
- **Discount Analysis:** Hats had the highest discount application rate at 50%.
- **Product Performance:** Gloves recorded the highest average review rating of 3.86.
- **Subscription Analysis:** Subscribers contributed $62,645 in revenue, while non-subscribers contributed $170,436.
- **Age Group Analysis:** Young Adults generated the highest revenue contribution among the four age groups.

## Business Recommendations

Based on the analysis, the following strategies were identified:

- **Improve Customer Retention:** Introduce loyalty programs to encourage repeat purchases.
- **Increase Subscription Adoption:** Promote exclusive subscriber benefits.
- **Optimize Discount Strategies:** Evaluate discount effectiveness across product categories.
- **Improve Product Positioning:** Highlight highly rated and frequently purchased products.
- **Targeted Marketing:** Develop customer-segment-specific marketing campaigns.

## How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/ak04amit/customer-trends-data-analysis-SQL-Python-PowerBI.git
```

2. Navigate to the project directory:

```bash
cd customer-trends-data-analysis-SQL-Python-PowerBI
```

3. Install the required Python libraries:

```bash
pip install pandas numpy sqlalchemy psycopg2-binary jupyter
```

4. Open the Jupyter Notebook:

```bash
jupyter notebook
```

5. Configure your PostgreSQL database connection and execute the notebook.

6. Execute the SQL queries using PostgreSQL.

7. Open the `.pbix` file using Microsoft Power BI Desktop to explore the interactive dashboard.
